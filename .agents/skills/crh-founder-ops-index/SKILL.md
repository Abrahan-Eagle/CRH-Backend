# crh-founder-ops-index

Índice de lectura para **founder / CTO** en Iglesia CRH. Fuentes principales: [awesome-ceo](https://github.com/kuchin/awesome-ceo), [awesome-cto](https://github.com/kuchin/awesome-cto), [awesome-tpm](https://github.com/kuchin/awesome-tpm).

**No sustituye** las skills operativas: `crh-launch-piloto`, `crh-fundraising-narrative`, `crh-empresa-ve`.

## Cuándo usar este índice

| Situación | Leer primero (externo) | Skill CRH después |
|-----------|------------------------|---------------------|
| Preparar ronda pre-seed | awesome-ceo → Fundraising | `crh-fundraising-narrative` |
| Primeros 90 días post-wire | awesome-cto → «Your first 90 days» | `crh-launch-piloto` |
| Due diligence técnica inversor | awesome-cto → Due diligence | `crh-investor-materials` + tests repo |
| Crisis / runway | awesome-ceo → Adapting to Endure (Sequoia) | `crh-financial-model` PROYECCION §7 |
| Contratar y escalar equipo | awesome-ceo → Hiring; awesome-cto → Hiring | `crh-lanzamiento-roles` |
| Coordinar hitos multi-equipo | awesome-tpm | `crh-launch-piloto` |
