# CRH Marketing Psychology

Persuasión **ética** para app congregacional y venta B2B a iglesias. Leer `docs/product-marketing-context.md` y `docs/BRAND_CRH.md` primero.

## Cuándo usar

- Copy para landing iglesia, email pastor, propuesta B2B.
- Diseño de flujos onboarding (par con `crh-onboarding-cro`).
- Evitar dark patterns en donaciones o registro.

## Principios aplicables a CRH

| Principio | Uso ético CRH | Evitar |
|-----------|---------------|--------|
| Reciprocidad | Valor gratis (devocional, evento) antes de pedir registro | Regalo con trampa |
| Prueba social | "X iglesias usan CRH" (solo si verificado) | Testimonios inventados |
| Autoridad | Endorsement pastoral real | Falsa credencial |
| Escasez | Cupos evento real | "Últimas plazas" falso |
| Compromiso | Checklist activación miembro | Presión de donación |

## Reglas pastorales

1. **No manipular** emociones de culpa para donaciones.
2. **Transparencia** en pricing SaaS (`crh-pricing-strategy`).
3. **Opt-in** explícito para push y email.
4. Invocar `crh-llm-judge` si el copy es masivo.

## Output

- Lista de principios aplicados al copy propuesto.
- Riesgos éticos identificados.
- Alternativas más alineadas a marca CRH.
