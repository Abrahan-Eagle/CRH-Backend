# Skills startup CRH — qué usar y qué evitar

> **Última actualización:** 1 junio 2026.  
> Adaptado desde ZonixPharma founder-playbook; dominio **Iglesia CRH** (app congregacional / SaaS multi-iglesia).

## Usar siempre (Jarvis local)

| Skill | Uso |
|-------|-----|
| `crh-startup-context` | Contexto, tiers, Market Type — **primero** |
| `crh-lanzamiento-docs` | Router pack + anti-patrones |
| `crh-empresa-ve` | C.A., RIF, SAFE, laboral (si aplica VE) |
| `crh-fundraising-narrative` | Pitch, mensaje inversor |
| `crh-investor-materials` | Data room, CHECKLIST |
| `crh-financial-model` | PROYECCION, UNIT — cifras `[PENDIENTE]` hasta OK humano |
| `crh-launch-piloto` | Plan lanzamiento app congregación |
| `crh-church-partnerships` | Alianzas iglesias / denominaciones B2B |
| `crh-legal-contracts-ve` | Contratos SaaS iglesia–proveedor |

## Cuándo NO usar Spec Kit

| Tarea | Herramienta |
|-------|-------------|
| Pack `docs/Lanzamiento/` | `crh-lanzamiento-docs` |
| Pitch / finanzas | `crh-fundraising-narrative`, `crh-financial-model` |
| Feature producto API+app | Spec Kit + `crh-*` dominio |

## Anti-patrones

| Recurso | Motivo |
|---------|--------|
| Cifras inventadas por IA | Solo `[PENDIENTE]` o docs aprobados |
| Skills dominio Pharma (`zonix-*`) | No aplican a CRH |
| blue-ocean puro | Mercado existente (apps iglesia / herramientas pastorales) |
